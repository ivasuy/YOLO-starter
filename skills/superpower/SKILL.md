# Superpower Bundle

This folder contains the bundled Superpowers workflow chain used by the starter.

Use these skills in this order when applicable:

1. `using-superpowers`
Call at the start of any new session or task.
Path: `skills/superpower/using-superpowers/SKILL.md`

2. `brainstorming`
Call for vague features, product direction, UX ideas, and behavior changes before implementation.
Path: `skills/superpower/brainstorming/SKILL.md`

3. `writing-plans`
Call after the spec/design is approved and the task needs a multi-step implementation plan.
Path: `skills/superpower/writing-plans/SKILL.md`

4. `subagent-driven-development`
Call when executing an implementation plan with independent tasks and reviewer loops.
Path: `skills/superpower/subagent-driven-development/SKILL.md`

5. `systematic-debugging`
Call before fixing any bug, failing test, build failure, or unexpected behavior.
Path: `skills/superpower/systematic-debugging/SKILL.md`

6. `using-git-worktrees`
Call before isolated implementation, parallel agent work, or task-by-task worktree execution.
Path: `skills/superpower/using-git-worktrees/SKILL.md`

7. `test-driven-development`
Call before implementing any feature, bug fix, refactor, or behavior change.
Path: `skills/superpower/test-driven-development/SKILL.md`

8. `finishing-a-development-branch`
Call when implementation is done and merge, PR, or cleanup decisions remain.
Path: `skills/superpower/finishing-a-development-branch/SKILL.md`

This bundle is the portable local source of truth for the starter on machines without a user-level Superpowers install.
